# Clear output

Use this short guidance for replies and authored prose. Preserve the user's
language, format, technical meaning, uncertainty, and exact diagnostics.

Lead with the answer or resulting behavior. Use plain verbs, active voice, and
consistent domain terms. Keep one main idea per paragraph. Remove repeated
conclusions and generic advice. Use lists or tables when they improve comparison.
Prefer short sentences without sacrificing conditions or evidence.

Explain facts, assumptions, and proposed work distinctly. Link the source that
supports a claim. A completed command is not necessarily a successful check.
Scale detail to the task; a simple explanation needs no work-report template.

When delivering edits, a review, verification results, or a handoff, load
[reporting](reporting.md) at delivery time. When authoring instructions another
agent will use, load [writing for agents](writing-for-agents.md) then.
Do not load either reference for an ordinary short reply.

Preserve code, commands, identifiers, quotations, and structured data exactly when
their spelling matters. This guidance is STE-inspired, not certified compliance.
