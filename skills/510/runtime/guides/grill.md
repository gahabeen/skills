# 510 grill

Stress-test the plan or decision supplied after `510 grill`, or the subject already
established in the conversation. If none is identifiable, ask for it.

Use [grilling](grilling.md) to resolve decision dependencies and challenge assumptions.
When terminology, domain relationships, or a consequential architectural decision
needs resolution, load [domain modeling](domain-modeling.md) and record agreed
terms and decisions using the project's conventions.

Reuse existing answers, source evidence, and a selected [exploration](explore.md).
Keep tentative options distinct from accepted decisions. When no direction has
been proposed, continue exploration if that fits the request. Write settled
decisions as they emerge; a discussion-only request keeps notes in the conversation.

Finish with the agreed outcome, document paths, and unresolved decisions, following
[output guidance](output.md). The invocation authorizes the interview and its
documents. Continue implementation when already requested and its necessary
decisions are settled. No setup or static analysis is needed.

Adapted from Matt Pocock's `grill-with-docs`; see
